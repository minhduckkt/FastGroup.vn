Siemens 6ES7431-7QH00-0AB0 – Module I/O analog

Module I/O analog SIMATIC S7-400 — Analog input SM 431, isolated 16 AI; resolution 16 bit.

Siemens Việt Nam / PLC S7-400 và S7-400H / Siemens 6ES7431-7QH00-0AB0

Siemens 6ES7431-7QH00-0AB0 là module I/O analog thuộc dòng SIMATIC S7-400. Mô tả đặt hàng theo Siemens: SIMATIC S7-400, analog input SM 431, isolated 16 AI; resolution 16 bit, U/I/Resistor/Thermocouple/Pt100 , alarm, diagnostics. Thông số nổi bật của 6ES7431-7QH00-0AB0: Số ngõ vào analog (AI): 16; Điện áp nguồn: 24 V; Only required for supplying 2-wire transmitters; Tổn hao công suất: 4.5 W; Kích thước (R×C×S): 25 mm x 290 mm x 210 mm.

Tên gọi khác: PLC I/O module; module vào/ra PLC.
