Siemens 7NG0340-0CA01-0CF2 là transmitter nhiệt độ hiện trường SITRANS TF320 thuộc dòng SITRANS TF320. Mô tả đặt hàng theo Siemens: SITRANS TF320 Temperature transmitter with single chamber enclosure for wall or pipe mounting, one configurable input and a galvanically isolated 2-wire output. HART (4 … 20 mA) Input 1 RTD Pt100 IEC 60751 4-wire None None CJC Die-cast aluminum enclosure Flameproof enclosure (Ex d) / Explosion proof (XP) 2 x M20 x 1.5 / closed Local operation (lid with glass window).

Tên gọi khác: temperature transmitter; bộ chuyển đổi nhiệt độ, bộ chuyển đổi tín hiệu nhiệt độ.
