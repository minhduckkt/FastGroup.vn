Siemens 6GK7443-1EX31-0XE0 là module truyền thông thuộc dòng SIMATIC S7-400. Mô tả đặt hàng theo Siemens: Communications processor CP 443-1; 2x 100 Mbps (IE switch); RJ45 ports; ISO; TCP; UDP; PROFINET IO controller; S7 communication; Open communication (SEND/ RECEIVE); S7 routing; IP configuration via DHCP/ block; IP access control list; time synchronization; extended web diagnostics; fast startup; support for PROFIenergy. Thông số nổi bật của 6GK7443-1EX31-0XE0: Switch có quản lý: Không; Cấp bảo vệ: IP20; Kiểu sản phẩm: CP 443-1; Kích thước (R×C×S): 25 mm x 290 mm x 210 mm.
