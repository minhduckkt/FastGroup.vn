Fast Group Engineering là nhà phân phối được Qlight cấp Certificate of Distributor, cung cấp QTG60L-IOL chính hãng tại Việt Nam cho nhà máy, nhà thầu EPC và đơn vị tích hợp hệ thống: đối chiếu cấu hình theo đúng mã đặt hàng, kiểm tra tồn kho và lead time, nhập khẩu kèm CO/CQ.

Tính năng theo catalog Qlight

  • Modular LED steady/flashing type signal tower lights
  • Excellent visibility from a distance with the use of a special color diffusing lens
  • The addition of modules and change in color arrangement can be achieved without the use of tools by using the Lock-type structure
  • Supports Four Operating Modes for Versatile Environmental Adaptability - Simple Mode: Enables basic on/off control of individual light sources. - Advanced Mode: Allows configuration of on/off and strobe timing for each light source. - Level Mode: Suitable for process operations using percentage-based input to control light output. - Demo Mode: Demonstrates various functions sequentially.
  • Supports Seven Light Source Operations for Enhanced Visibility (On / Slow Blink / Medium Blink / Fast Blink / Strobe 1, 2, 3)
  • Advanced LED signal tower light integrated with IO-Link technology
  • Ideal for next-generation smart manufacturing systems (Industry 4.0)
  • IO-Link Version: V1.1
  • Data transmission speed: 38,400 bps(COM2)
  • Connector: M12-5Pin(Male)-Class A
  • High-volume buzzer Max. 100dB(at 1M), Waterproof buzzer Max. 85dB(at 1M)
  • Plug & Play functionality enabled by international standard M12 connector
